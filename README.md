# 🌺 彼岸花抽獎系統 — 使用指南

## 快速開始

直接用瀏覽器開啟 `index.html`，無需安裝任何套件。

---

## 基本流程

### 1. 輸入名單
在左側「👥 抽獎名單」欄位中，**每人一行**輸入參與者名稱。系統會自動計算人數，並提示重複名單。

### 2. 設定獎項
在「🎁 獎項設定」區塊新增獎項：
- 輸入獎項名稱與數量
- 可新增多個獎項，點「＋ 新增獎項」增加
- 各獎項會顯示為中央區域的標籤頁

### 3. 選擇獎項並抽獎
- 點擊中央的獎項標籤頁選定要抽的獎
- 點「**開始抽獎**」或按 <kbd>Space</kbd> / <kbd>Enter</kbd> 啟動
- 抽中後顯示中獎者，再次按空白鍵或點畫面可繼續下一抽

---

## 功能說明

### 批量抽獎
在「批量 ___ 人」欄位輸入數量，一次可抽多位得獎者。

### 復原 / 重做
- <kbd>Ctrl+Z</kbd>：復原上次抽獎（恢復名單與庫存）
- <kbd>Ctrl+Y</kbd>：重做

### 匯出紀錄
右側「🏆 中獎名單」欄位點「**⬇ 匯出**」可下載 CSV 格式的完整中獎紀錄。

### 抽獎設定
- **抽中後自動剔除名單**：避免同一人重複中獎
- **快速模式**：略過滾輪動畫，直接顯示結果

---

## 神秘盲盒功能

盲盒讓每位得獎者親手翻牌選獎，獎項事先隱藏。

1. 在左側「🎲 神秘盲盒」區塊啟用盲盒
2. 勾選要納入盲盒的一般獎項，並設定各獎項的**權重**（越高越容易抽中）
3. 可新增「盲盒獨有獎項」（不在一般抽獎中出現）
4. 設定完成後點「**鎖定設定**」
5. 抽獎時選取「🎲 神秘盲盒」標籤頁進行抽獎
6. 中獎者看到翻牌畫面，點牌翻開即知獎項

## 快捷鍵一覽

| 按鍵 | 功能 |
|------|------|
| <kbd>Space</kbd> / <kbd>Enter</kbd> | 開始抽獎 / 繼續下一位 |
| <kbd>Ctrl+Z</kbd> | 復原上次抽獎 |
| <kbd>Ctrl+Y</kbd> | 重做 |
| <kbd>Ctrl+K</kbd> | 觸發隱藏特效（主持人彩蛋） |

---

## 注意事項

- 所有資料存於瀏覽器 **localStorage**，清除瀏覽器快取會遺失設定
- 獎項全部抽完（庫存歸零）後，標籤頁會標示「售罄」
- 重設系統（🗑 重設全系統）會清除所有名單、獎項與紀錄，操作前請先匯出
